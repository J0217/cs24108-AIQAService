# EA 17 建模与证据截图清单

本清单只服务 E-多端接入模块和实验一报告。模型图必须用 Enterprise Architect 17 手工绘制，禁止用 PlantUML、SVG、脚本或 AI 生成替代。截图必须来自真实运行环境，不用拼接或示意图。

## 一、安装 EA 17

1. 从课程群/学校软件平台获取 Sparx Enterprise Architect 17 安装包和 License Key。EA 是商业软件，个人不要自行购买。
2. 运行安装包，按默认路径安装。安装完成后启动 EA。
3. 在 `Help → Register and Manage License` 中输入学校提供的 Key；如果是浮动授权，选择 License Server 并填写课程提供的地址。
4. 新建项目：`File → New Project`，保存为 `model/AIQAService-Plan.qea`，模板选 `Basic` 或空模型。
5. 在 Project Browser 建立四个包：`01 需求`、`02 设计`、`03 部署`、`04 配置`。后续图都放在对应包内。
6. 完成后把 `model/AIQAService-Plan.qea` 提交到仓库，报告图题下会写“绘制：EA 17 手工绘制・源文件 model/AIQAService-Plan.qea”。

## 二、三张必画图

### 图 2-1 项目组织与接口协作关系（组件图或对象图）

放在 `02 设计` 包，图类型选 Component Diagram。

- 组件：`A-用户管理`、`B-对话管理`、`C-AI引擎`、`D-公告管理`、`E-多端接入`。
- 外部参与者：`小程序用户`、`API调用方`。
- 关系：
  - 小程序用户 → E：使用小程序；
  - API调用方 → E：调用 `/api/v1/*`；
  - E → A：`/api/auth/*`，JWT；
  - E → B：`/api/chat/*`，JWT；
  - E → C：回复生成（经 B 或服务方法）；
  - E → D：`/api/announcement/*`，JWT。
- 在连接线上标注协议与鉴权方式，例如 `HTTPS + JWT`、`HTTPS + X-API-Key`。
- 图名写 `图 2-1 项目组织与接口协作关系`。

### 图 7-1 dev/test/prod 部署拓扑（部署图）

放在 `03 部署` 包，图类型选 Deployment Diagram。

- 节点：
  - `用户手机`：微信小程序，游客模式/测试号；
  - `开发机`：Windows，Python 3.14.6，Flask 5000 端口，SQLite `instance/ai_qa_service.db`；
  - `测试运行`：Python unittest + 临时 SQLite，`test_client`；
  - `生产服务器（规划）`：gunicorn + PostgreSQL，当前未部署；
  - `微信平台`：`wx.login` 换取 code。
- 连接：手机 → 开发机 `http://局域网IP:5000`；开发机 → 微信平台 HTTPS；生产服务器与开发机之间标“规划，未部署”。
- 图中必须把“未部署”标出来，不能画成已上线。
- 图名写 `图 7-1 dev/test/prod 部署拓扑`。

### 图 12-1 分支与配置管理流程（活动图）

放在 `04 配置` 包，图类型选 Activity Diagram。

- 流程：`在 feature/2024213575-duoduan 提交` → `发起 PR` → `组员评审` → `评审通过？`
  - 否：返回修改；
  - 是：`合入 develop` → `回归测试 7 条用例` → `通过？`
    - 否：返回修改；
    - 是：`合入 main` → `打 tag lab1-plan-v1.0` → `结束`。
- 在开始节点旁标注“当前仓库仅 main 分支，流程为本次实验要建立的基线”。
- 图名写 `图 12-1 分支与配置管理流程`。

## 三、导出要求

1. 每张图在 EA 中 `Publish → Save as Image`，格式 PNG，300 DPI，白底。
2. 宽度约 1800—2400 像素，保证插入 A4 后文字可读。
3. 文件名必须与报告脚本约定一致，放到 `docs/assets/`：
   - `fig-2-1-org.png`
   - `fig-7-1-deploy.png`
   - `fig-12-1-branch.png`
4. 导出后重新运行 `py -3.10 generate_lab1_report.py`，脚本会自动插图并生成图目录。
